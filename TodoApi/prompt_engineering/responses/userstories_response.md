1. Como usuario autenticado, quiero poder ver todas mis tareas para poder tener una visión general de mis responsabilidades.
2. Como usuario autenticado, quiero poder ver los detalles de una tarea específica para recordar los detalles y el estado de la misma.
3. Como usuario autenticado, quiero poder crear una nueva tarea con un título, estado y categoría específicos para organizar mis responsabilidades de manera efectiva.
4. Como usuario autenticado, quiero poder actualizar una tarea existente con un nuevo título, estado o categoría para mantener la información actualizada.
