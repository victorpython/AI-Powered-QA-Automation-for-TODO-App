Aquí tienes las historias de usuario en formato Markdown:

```markdown
# Historias de Usuario

## US-01
Como **nuevo usuario** quiero **registrarme en la aplicación** para **poder acceder a las funcionalidades disponibles**.

## US-02
Como **usuario registrado** quiero **iniciar sesión con mis credenciales válidas** para **acceder a mi lista de tareas**.

## US-03
Como **usuario** quiero **poder alternar entre diferentes temas** para **personalizar la apariencia de la aplicación según mis preferencias**.

## US-04
Como **usuario** quiero **cerrar sesión de manera segura** para **proteger mi información personal y asegurar que nadie más pueda acceder a mi cuenta**.

## US-05
Como **administrador** quiero **ver un registro de usuarios** para **gestionar las cuentas y asegurar que solo los usuarios autorizados tengan acceso**.

## US-06
Como **usuario** quiero **recibir un mensaje de error claro** cuando intento iniciar sesión con credenciales inválidas para **entender qué debo corregir**.
```

Estas historias de usuario reflejan las necesidades y acciones deseadas en la aplicación, así como los beneficios que se esperan obtener de ellas.
